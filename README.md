# Byteclass
Byteclass is a software development company focused on building modern web applications, AI-powered solutions, SaaS platforms, and digital products for startups and businesses.


## Getting Started

### Prerequisites
Make sure you have installed:
* Node.js 18+
* npm

### Installation
Clone the repository:
```bash
git clone https://github.com/Shriyash-Kurud/byteclass-site.git
cd byteclass-site
```

Install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open:
```text
http://localhost:3000
```

### Production Build

Build the project:
```bash
npm run build
```

Start the production server:
```bash
npm start
```
